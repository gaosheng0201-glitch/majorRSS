上一轮八个都是皮肤——皮肤按定义就会过时，而且越"当下"的皮肤死得越快。这一轮换成结构：记忆点长在版面逻辑里，不长在材质、颜色、光影里。判据很简单——把颜色全抽掉、把纹理全去掉，它还认得出是它吗？下面三个都能通过这一关。

T1 · 台账（Ledger） 把时间做成一根固定的轴，每条线索是账簿上的一行，证据在固定的列里累积。灵感来源是火车时刻表和复式账簿——这两样东西的版式一百五十年没变过，因为它们解决的是同一个问题：让一堆事实按同一个坐标可比。软件里几乎没人这么做，所以它同时满足"眼熟"和"没见过"。记忆点是那根时间轴和那几根发丝线，跟颜色无关。

为什么这三个不会过时：它们的辨识度全部来自「信息怎么排」，而不是「表面怎么渲染」。渲染技巧一旦被操作系统内置（阴影、玻璃、渐变都经历过），你的独特性就当场归零；而版面逻辑不会被内置，因为它是你这个产品特有的信息结构长出来的。

三个的性格差别：T1 台账最冷静、密度最高，适合每天看很多条的人；T2 Unigrid 最有编辑主张，一屏只讲一件事，最像"给你一个人办的报"；T3 面板最像专业设备，适合"我的监测系统在运转"这种心理。

三个都能套任意皮。浅色深色、衬线无衬线、暖调冷调都换得动，身份不变——这正是"五年不过时"的技术定义：可以换皮而不失去自己。
