# UI 设计方向：安静的仪器（Quiet Instrument）

> 2026-07-28 · 设计意图文档，不是实施清单。
> 上位文档：[vision_and_blueprint.md](vision_and_blueprint.md)（尤其 §2「信息是主角」与「信息设计纪律」）。
> 本文回答的问题：**AI 原生应用的界面凭什么和早期应用长得不一样？**

---

## 1. 现状诊断：同质化不是审美问题，是结构问题

现在的界面是 Mantine 默认主题（indigo 主色、Outfit 字体、lucide 图标）+ 左侧九个页面（Dashboard / Radar / Discovery / Subscriptions / Sources / Briefing / FactChecker / Billing / Settings）+ 卡片网格 + 徽章。

同质化的根因不在配色，在于**导航结构泄露了数据库结构**：有 tracker 表就有订阅页，有 source 表就有源页。用户被要求先回答"我要去哪个页面"，才能回答"我想知道什么"。

> 这是 CRUD 时代的界面语法：名词（页面）+ 动词（按钮）。
> 换了配色、换了字体、换了圆角，语法没变，就还是同一个应用。

## 2. 三代界面语法，以及我们要写的第四代

| 代 | 主体 | 界面形态 | 用户负担 |
|---|---|---|---|
| 桌面 GUI | 文件/文件夹（名词） | 列表、树、图标网格 | 自己组织对象 |
| Web SaaS | 数据表（名词） | 侧边栏导航 + 仪表盘卡片 | 自己在页面间导航、自己汇总 |
| 聊天式 AI（2023–） | 对话轮次 | 一个输入框 + 消息流 | 状态全在历史里，每次重述上下文，无法回看、无法调参 |
| **意图原生（我们）** | **意图（Watch Target）** | 意图轨 → 增量阅读面 → 证据面 | 只需说出"我想知道什么"，状态由系统持有并**可见可改** |

聊天式 AI 看起来是意图优先，实际是**退化的终端**：意图说完就消散在滚动历史里，不是一个可以被检视、调整、复用的东西。

**我们的差别点：意图是一等持久对象。** 用户说"我要盯 Anthropic 的 API changelog"，系统把它固化成一个活体（画像、源组合、节奏、预算、已知状态），永远在屏幕上，可点开、可调、可关。这是这个产品结构上就有、别人抄不走的东西——它是 Watch Target 架构的界面投影。

### 北极星一句话（用来裁决一切 UI 争议）

> **屏幕上的每个像素，要么是一个意图，要么是这个意图的变化，要么是这个变化的证据。**
> 三者之外的东西（统计、徽章、导航、品牌装饰）默认不配上主屏。

对应结构：**意图 → 增量 → 证据**（左 → 中 → 按需右）。所有现有页面都不是并列关系，而是这三层的属性：
- Sources / Subscriptions / Discovery → 某个意图的"我在替你看哪些地方"（意图详情内，不是顶层页面）
- Briefing → 就是阅读面本身在"多日未见"时的形态，不是另一个页面
- Dashboard / Billing → 折叠进意图详情的成本行 + 一个诊断抽屉
- FactChecker → 证据面的交互，不是页面

**日用界面只有一个。** 这条蓝图里已经写了，但没有被界面结构兑现。

## 3. 设计语言（探索中，未定稿）

> 2026-07-28 更新：本节原来只写了「深色 + 琥珀 + 等宽」一种皮肤，作者判断它仍是"AI 被要求做得有个性时的默认答案"（终端/Bloomberg 那套），且把内容自带的视觉素材全剥光了。
> **两条修正已确立**：① 色彩从内容里来（新闻配图、平台标识本身就是彩色语言），不从 chrome 里刷；② 需要材质与景深，层级用光影和物理感表达，不用边框和徽章。
> 另外三个候选世界见 [ui_mock_directions.html](ui_mock_directions.html)：**A 每日刊**（暖白纸 + 报纸版面 + 刊号）、**B 玻璃与景深**（重要性 = 物理高度）、**C 接收机**（颜色 = 频道身份）。
> §2 的意图结构、§4.5 的易用性契约、§6 的验收规则与皮肤无关，仍然成立。下面这套是候选之一，不是结论。

### 候选：安静的仪器

两层，严格分工，互不污染：

**编辑层（内容是主角）** —— 衬线大字标题、宽留白、报纸式栏宽。负责回答"发生了什么"。
**仪器层（元信息安静）** —— 等宽小字、灰阶、刻度图形。负责回答"什么时候 / 几个来源 / 多确定 / 多快"。

这个"两种字体各司其职"本身就是识别度：**看到衬线，你在读事实；看到等宽，你在读证据。** 绝不用彩色徽章去装饰编辑层。

### 签名元素：证据脊（Evidence Spine）

每条线索的元信息行里有一条 ~140px 的微型时间刻度：

- 每个刻度 = 一个独立来源，横向位置 = 它出现的时间
- 形状 = 来源身份：空心点（社交/线报）· 实心点（媒体转述）· 方块（一手/官方）
- 生命周期不用文字标签，**用图形自然表达**：只有空心点 = LEAD；点变多变密 = CORROBORATED；方块出现 = CONFIRMED
- 共振 = 刻度在时间上聚成一簇——**图形本身就是那个判断**，不需要"共振"徽章

这是 Tufte sparkline 的产品化：零 chrome、高密度、极独特。三个月后用户记得的是"左边有小刻度的那个应用"。它同时是 logo、网站、节目片头可以复用的品牌资产（OnlyFourBot 用同一套语言）。

退化规则：来源 < 2 时，脊退化成一根淡线——"单源未证实"本身就是要传达的信息，不是缺陷。

### 颜色：一色系统

- 底：偏暖的墨色（不是纯黑，不是紫蓝渐变）
- 字：米白
- 仪器层：三级灰阶
- **唯一的彩色 = 琥珀，唯一的含义 = "这条值得打扰你"**

第二种彩色出现即 bug。琥珀呼应终端 / 雷达 / 仪表的历史语言，且与满街的紫蓝 AI 渐变正好相反。允许一处发光（共振指示灯的极轻辉光），稀缺才有效。

### 其余规范

- 卡片和边框几乎为零，分隔靠留白与 1px 线
- 一屏 5–9 条，不是 40 条
- 动效只有两类：增量落位（慢、微上移、交错 60ms）、证据面滑出。禁止骨架屏闪烁墙
- 图标能不用就不用；必须用时只用刻度/几何，不用拟物小图标

## 4. AI 原生的四个交互形态（真正的代差在这里，不在皮肤）

1. **有底的 feed。** 滚到底就是结束：「到底了，你追平了。」空状态不是错误状态，是产品的目标状态——大多数时候打开应用应该几乎是空的：「今天有 2 件事值得你知道。」这直接兑现"注意力保护"，也是和无限下拉 feed 最直观的气质分野。
2. **水位线。** 界面上永远有一条明确的"你上次在这里"，回访的叙事是"自上次以来"，不是"未读 700 条"。追赶简报 = 水位线以上的内容，不是另一个页面。
3. **AI 的每次行动都在界面上留下可逆的痕迹。** 用户在意图线上说"别再给我营销号"，结果不是一段聊天回复，而是那个意图的排除规则**多了一行结构化的、可点、可撤销的记录**。这是意图原生 vs 聊天式的关键差别，也是信任的唯一来源。
4. **溯源即交互，且强制。** 任何一句合成结论可点开高亮它依据的源片段。UI 层硬约束：**没有引用的句子不允许渲染**。求真产品被抓到一次编造即品牌破产（蓝图 §3.3-4）。

另外，主动性要可见但不吵：意图轨底部一个极小的常驻心跳——"值班中 · 正在看 27 个源"。它不是 loading spinner，是"有人在替你守着"的表达。

## 4.5 易用性契约（作者补充，2026-07-28，优先级高于风格）

> 原话：好用、直观；没用过的人凭其他软件的操作习惯立马上手；看信息的地方方便看，做设置的地方容易设置，不能有歧义。

这条纠正了上面所有主张里最危险的倾向：**独特性只能长在表层，不能长在结构上。**（Jakob 定律：用户绝大部分时间在别的软件里，他们期待你的软件和别人一样工作。）因此定三条硬约束：

**① 骨架保守，表皮独特。**
左侧常驻可见导航**保留**，不做"纯命令面板"。意图轨长得像所有人熟悉的侧栏列表（可点、有高亮、有滚动），只是列的内容是意图而不是页面。§2 说的"取消名词导航"指的是**减少并合并顶层条目**（九个 → 意图列表 + 一个「设置」入口），不是取消可见导航。第 3 节的意图线是**熟手的快车道，不是唯一入口**——任何用意图线能做的事，界面上都必须有一个看得见、点得到的常规做法。

**② 三种界面区分对待，不用同一套调门。**

| 区域 | 调门 | 规则 |
|---|---|---|
| 阅读面（雷达 / 线索 / 简报） | 最有个性 | 编辑排版、证据脊、留白；个性必须服务于"看得快、看得懂" |
| 操作面（新建意图、调节奏、反馈） | 中性 | 常规表单控件 + 明确主按钮；每个操作说清后果 |
| 设置面（模型 Key、预算、账号、更新） | **最无聊、最常规** | 左标签右控件、分组、每项一句说明、即时保存并有反馈；不搞创新 |

设置页是唯一允许"看起来像普通软件"的地方——而且**必须**像。用户在这里要的是确定性，不是气质。

**③ 无歧义 = 图形永不独自承担意义。**
证据脊、生命周期、共振都是**文字含义的加成**，不是替代：元信息行里始终保留可读文字（`2 小时前 · 6 个来源 · 已证实`）。刻度图形负责一眼扫，文字负责确认，hover 有 tooltip 解释。配色同理：琥珀旁边永远有一句"为什么打扰你"。任何"你得学会我们的符号系统才能用"的设计，一律否决。

**④ 首次使用可自证。** 空状态里写清"下一步做什么"（一个按钮：新建关注目标）；每个新概念（意图 / 线索 / 佐证 / 共振）在首次出现处有一句人话解释，可关掉。不做引导蒙层教程——需要教程才会用，说明结构错了。

## 5. 参考（按用途分类，都不是拿来抄布局的）

**仪器与信息密度**：Bloomberg Terminal（琥珀单色 + 等宽 + 零装饰，最接近我们要的气质）；航管 / 航海雷达显示；Teenage Engineering OP-1、TX-6 的丝印刻度语言；Dieter Rams / Braun 的仪表面板。

**数据即排版**：Edward Tufte 的 sparkline 与 small multiples（证据脊的直接来源）；FT 与 The Economist 的图表规范；NYT The Upshot。

**阅读气质**：Readwise Reader、Instapaper、Are.na；NYT Morning Briefing 的排版；Stratechery 的极简正文。

**意图优先与命令**：Raycast（命令面板即唯一入口）；Linear（键盘优先 + 严格到偏执的设计语言）；Superhuman 的 "You're all done"（有底 feed 的著名先例）；Arc 的 Little Arc（少即是入口）。

**变化与证据的呈现**：git diff 的心智模型；Slack 的未读分割线（水位线原型）；Perplexity 的引用角标（溯源交互的量产范例）；Elicit（研究型 AI 的证据表）。

**反例（明确不要）**：左边聊天右边卡片的 AI SaaS 双栏；玻璃拟态 + 紫蓝渐变 + 发光边框；首屏四个 KPI 卡片；每条内容三个彩色徽章。

## 6. 验收规则（防止"为了好看而好看"）

1. 任何视觉元素必须对应一个用户真会问的问题；答不出就删。
2. 彩色只有一种含义。第二种含义的彩色出现 = 设计缺陷。
3. 首屏元信息不超过一行文字。
4. 空状态是终点不是错误——它必须被当成一屏成品来设计。
5. 每条 AI 生成的句子都能点开看到源片段，否则不渲染。
6. 改动后仍满足蓝图的"3 分钟摄入一天"，且首屏元信息密度没有上升。

## 7. 落地路径（与 R6「UI 换心脏」对齐，分阶段可回退）

| 阶段 | 内容 | 风险 |
|---|---|---|
| P0 | 静态 mock（已出，见 `docs/ui_mock_quiet_instrument.html`）+ 本文档定稿 | 无 |
| P1 | Token 层：颜色 / 字体 / 间距 / 一色系统替换 Mantine 主题，**结构不动** | 低，立刻改变气质 |
| P2 | Radar 页换成 意图轨 + 阅读面 + 证据脊 + 水位线 | 中，需线索接口给出 source 时间戳 |
| P3 | 意图线取代顶层导航；Sources / Subscriptions / Discovery 收进意图详情 | 中高，等功能重构稳定后做 |
| P4 | 证据面（点句子对照源片段）+ 反馈痕迹可逆化 | 依赖 R5 合成带引用 |

P1 可以现在做且不与功能重构冲突；P2 之后要等管线重构落定。
