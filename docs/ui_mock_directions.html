关于配色

三个方向都没有主色。A 是纸 + 印刷红；B 几乎无色，靠光；C 的颜色属于频道不属于界面。真正的色彩来自新闻配图和平台标识——那是内容自带的，不是我们刷上去的。

关于层级

A 用版面（头条 / 要闻 / 边栏），B 用景深（浮起 / 平放 / 凹陷），C 用材质（发光的卡片 / 普通卡片）。三种都比"加一个彩色徽章"更接近真实世界的阅读经验。

还能混

比如 B 的玻璃壳 + A 的报纸内页；或 C 的频道色 + B 的景深。灵感阶段不必二选一，先挑出你一眼有反应的元素。
